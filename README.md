# AI Interview Preparation Platform

An AI-powered mock interview and career preparation platform designed to help candidates practice, analyze, and excel in job interviews. The platform simulates technical and behavioral interviews, providing instant feedback and performance metrics.

## Key Features

*   **AI Mock Interviews:** Technical and behavioral interview simulations.
*   **Intelligent Feedback:** Real-time analysis of speech, communication pacing, and response quality.
*   **Resume Analyzer:** ATS-compatibility evaluation and skill gap identification.

## Tech Stack

*   **Frontend:** Next.js, Tailwind CSS
*   **Backend:** FastAPI / NestJS
*   **AI/ML:** Gemini API, OpenAI API
*   **Database:** PostgreSQL, Redis

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/hirdeshds/2026-27_IT-B_202401100600089.git
   ```
2. Frontend setup:
   ```bash
   cd src/frontend && npm install && npm run dev
   ```
3. Backend setup:
   ```bash
   cd src/backend && pip install -r requirements.txt && uvicorn main:app --reload
   ```
